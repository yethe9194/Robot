## Compilation 

Le projet utilise un `Makefile` pour automatiser la compilation. Tous les fichiers exécutables et bibliothèques compilés seront placés dans le dossier `dist/`.

- **Compiler tout le projet** 
    make

- **Compiler les tests**
    make test

- **Visualiser la page HTML**
    make serve

- **Visualiser le rapport**
    make rapport

- **Nettoyer les fichiers**
    make clean
